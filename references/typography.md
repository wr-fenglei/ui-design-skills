# Typography and Information Scale

## Role and scale

Keywords: display, heading, body, metadata, numerals.

- Establish size relationships around the information priority.
- Let a single important value become the focal element when the task supports it.
- Keep supporting text visibly subordinate without making it tiny or faint.

## Typeface and form

Keywords: glyph width, stroke weight, counter, curvature, language.

- Evaluate the actual glyphs used, especially numerals and short display phrases.
- Distinguish a narrow glyph from inadequate spacing; changing tracking cannot repair every typeface choice.
- Check Chinese and Latin text separately rather than transferring settings mechanically.

## Rhythm

Keywords: line height, text width, tracking, baseline, line break.

- Tune these values together using real copy.
- Preserve a comfortable phrase rhythm; forced balanced wrapping is not inherently better than natural wrapping.
- Avoid ornamental punctuation when a short display label does not need it.

## Numeric alignment

Keywords: proportional figures, tabular figures, natural spacing.

- Use proportional figures when natural display rhythm matters.
- Use real tabular figures when changing or stacked numbers must align, if the font supports them.
- Do not imitate tabular figures by stretching glyphs or adding arbitrary per-character boxes.
- OpenType `tnum` means tabular figures; `numr` means numerators.

## Text color

Keywords: hierarchy, echo, contrast, backing surface.

- Choose text color in relation to the actual surface and nearby visual subject.
- Do not lower contrast so far that hierarchy becomes loss of information.

Check at the intended display size, not only in a large image preview.

Sources: [Tabular figures](https://learn.microsoft.com/en-us/typography/opentype/spec/features_pt#tnum), [Numerators](https://learn.microsoft.com/en-us/typography/opentype/spec/features_ko#numr).
