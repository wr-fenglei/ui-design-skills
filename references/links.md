# Reference links

Every source linked from this repository's earlier notes, merged and deduplicated on 2026-11-01. Links only: no third-party screenshots or media are kept here, and a link grants no reuse rights.

## Linear (baseline reference)

- [linear.app](https://linear.app/): home page; colours, type, spacing, shapes and the product-window technique, measured with `getComputedStyle`.
- [Linear /plan](https://linear.app/plan): feature-section template (H2 left, lead right, product panel, 2×2 features).
- [Linear /build](https://linear.app/build): same section template, second set of measurements.
- [Linear /method](https://linear.app/method): article layout with a large serif title and a numbered table of contents.
- [Behind the latest design refresh](https://linear.app/now/behind-the-latest-design-refresh): Linear's own account of the redesign; read for hierarchy and density, not for values.

## Apple platform

- [macOS (apple.com/os/macos)](https://www.apple.com/os/macos/): macOS 27 Mail render; three-pane ratio, list rows, selection by grey step, window shape.
- [Ars Technica macOS 27 review](https://arstechnica.com/gadgets/2026/09/macos-27-golden-gate-the-ars-technica-review/): macOS 27 Finder screenshots; sidebar ratio, toolbar grouping, window-corner comparison.
- [HIG: Toolbars](https://developer.apple.com/design/human-interface-guidelines/toolbars): window-anatomy diagrams (Finder, Notes); toolbar structure.
- [HIG: Sidebars](https://developer.apple.com/design/human-interface-guidelines/sidebars): sidebar row sizing behaviour.
- [HIG: Typography](https://developer.apple.com/design/human-interface-guidelines/typography): macOS text styles and tracking tables.
- [HIG: Color](https://developer.apple.com/design/human-interface-guidelines/color): system accent colours.
- [HIG: Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons): hit targets and image-button padding.
- [HIG: Layout](https://developer.apple.com/design/human-interface-guidelines/layout): window-edge placement rules.
- [HIG: Materials](https://developer.apple.com/design/human-interface-guidelines/materials): material hierarchy; Liquid Glass only on the floating functional layer.
- [WWDC25: Build an AppKit app with the new design](https://developer.apple.com/videos/play/wwdc2025/310/): control sizes including the new extra-large size.
- [Mail User Guide](https://support.apple.com/guide/mail/welcome/mac): Apple Mail message list and reading pane.
- [Calendar User Guide](https://support.apple.com/en-mide/guide/calendar/icl8c17e7f55/mac): Calendar week and day views.
- [Mac User Guide: Finder](https://support.apple.com/en-ie/guide/mac-help/mchlp2605/27/mac/27): Finder window, grouping and preview.
- [NSColor catalog (gist)](https://gist.github.com/martinhoeller/38509f37d42814526a9aecbb24928f46): community-measured macOS Sonoma semantic colours.
- [PureBasic forum: Tahoe button heights](https://www.purebasic.fr/english/viewtopic.php?t=87595): community, unverified push-button heights.
- [Reddit r/MacOSBeta: Tahoe window radii](https://www.reddit.com/r/MacOSBeta/comments/1l9zfdi/): community, unverified window corner radii.
- [YouTube: pre-Tahoe window radius](https://www.youtube.com/watch?v=EZkUZCCeqV0): secondhand source for the ≈10 pt pre-Tahoe radius.

## Design guidance

- [Stripe: Accessible color systems](https://stripe.com/blog/accessible-color-systems): foreground/background pairs and palette construction.
- [Adobe Spectrum](https://spectrum.adobe.com/): a full design system to study.
- [Spectrum: Using color](https://spectrum.adobe.com/page/using-color/): semantic colour roles and neutral surfaces.
- [Spectrum: Attention hierarchy](https://spectrum.adobe.com/foundations/attention-hierarchy): how area, contrast and surface set emphasis.
- [NN/g: Gestalt proximity](https://www.nngroup.com/articles/gestalt-proximity/): grouping by distance.
- [WCAG 2.2: Contrast (minimum)](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum): text contrast requirement.
- [OpenType `tnum`](https://learn.microsoft.com/en-us/typography/opentype/spec/features_pt#tnum): tabular figures.
- [OpenType `numr`](https://learn.microsoft.com/en-us/typography/opentype/spec/features_ko#numr): numerators.
