# UI Design Skills

A unified design skill for interfaces, components, visual assets, and app icons.

Start with [SKILL.md](SKILL.md). Read only the references relevant to the design problem.

## Design dimensions

- [Design principles](references/design-principles.md): attention, proportion, grouping, color roles, and material restraint.
- [Composition](references/composition-preservation.md): framing, scale, alignment, optical balance, and reference interpretation.
- [Grouping and hierarchy](references/grouping-and-hierarchy.md): proximity, common regions, navigation, and separators.
- [Color in context](references/color-in-context.md): foreground/background relationships, saturation, area, and contrast.
- [Typography](references/typography.md): scale, weight, supporting text, numerals, and language.
- [Shape and material](references/shape-and-material.md): silhouette, curvature, depth, glass, and detail density.
- [Icon design](references/icon-design.md): metaphor, structural exploration, and small-size identity.
- [Code and image collaboration](references/code-image-collaboration.md): shared baselines and editable implementation.
- [Image prompting](references/image-prompting.md): composition-first briefs and controlled edits.

## Visual references

- [Reference index](references/reference-index.md): bundled icon sheets and selected visual examples.
- [Design sources](references/design-sources.md): where to find references for specific design questions.

The references provide usable decision criteria, not a universal visual template. Included images are visual studies, not functional UI implementations. Reference-asset redistribution and commercial-use rights are not granted by this repository.
