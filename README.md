# UI Design Skills

持续积累 UI 设计方法、系统性技能与少量优秀典型示例的私有仓库。

当前聚焦 UI 设计。蔚负责调研、示例设计与制作、检查、整理和维护；用户通过审看、评价帮助校准审美。仓库价值在于可重复使用的方法和高质量参考，不在于文件数量。

## 工作方式

**调研 → 制作多个示例 → 用户评价 → 尝试修改 → 本地积累好示例 → 提炼方法或选入典型示例。**

- 日常示例是实践材料。即使某个效果得到认可，也先作为本地参考，不急着变成技能。
- 不好的示例可以尝试修改；仍不好就放下，不长期积累负面案例。
- 从多个好示例中观察是否能提炼设计理念、美学经验或可复用方法。
- 特别好、有代表性且很有价值的示例，本身也可以进入仓库，不必等待完整理论。
- 不默认向 ChatGPT Space / Library 存放练习归档、源包和工作笔记。交付审看所需的少量附件与长期知识沉淀分开。

详细规则见 [研究、实作、反馈与沉淀](docs/working-method.md) 与 [阶段性清理规则](docs/lifecycle.md)。

## 逐步形成的技能领域

以下是建设方向，不代表已经实现或验证：

- 整体统筹：明确目的、场景、参考与设计约束，选择需要的技能。
- 布局与空间：信息层级、比例、留白、对齐和密度。
- 色彩：颜色关系、面积比例、对比与主题。
- 形状与阴影：轮廓、曲线衔接、层次、光照与材质。
- 字体与字号：字形、字重、字距、行距、可读性和文字层级。
- 组件：组合基础设计选择，处理内容、状态与交互。
- 图标：形状、负空间、结构、材质与小尺寸识别。
- 页面：在已确定的基础设计上组织组件与完整页面，再考虑适当的动效。

现有 [App Icon Design](https://github.com/wr-fenglei/app-icon-design) 作为图标方法的基础来源；目前保持独立，不在此重复复制或宣称已经完成迁移。使用时实际阅读技能、原则与参考图。
