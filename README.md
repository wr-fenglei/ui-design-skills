# UI Design Skills

系统性的 UI 设计技能体系，积累可复用的设计方法与少量高价值典型示例。App Icon 是体系中的一项基础能力，不是平行的独立设计体系。

## 已有基础能力

- [App Icon Design](skills/app-icon-design/SKILL.md)：设计意图、轮廓、负空间、构图、材质、色彩、光照、探索与细化；包含原参考图与分析框架。
- [图标模块说明](skills/app-icon-design/README.md)

## 逐步建设的能力

整体统筹、布局与空间、色彩、形状与阴影、字体与字号、组件，以及在已确定基础上组合的页面设计。基础美观后再进一步研究动效。这些是建设方向，不代表已经实现的技能。

每项能力逐步明确输入、设计方法、产出、验收和边界，并依据实际效果组合 LLM/代码的精确实现与图像生成的局部探索能力。不以完整页面生成图替代可编辑、可验证的实现。

## 收录范围

- 经实践提炼、可复用的方法和设计技能。
- 少量特别好、有代表性的示例；无需等待完整理论，但应保留效果、制作方法、为什么好和使用边界。
- 普通练习、过程文件与未筛选素材不默认进入仓库。

详见 [收录标准](docs/curation.md) 与 [图标迁移记录](docs/icon-migration.md)。
