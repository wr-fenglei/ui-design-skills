# Systems

Each folder is one Figma design system built with [METHOD.md](../METHOD.md): a Figma link, page exports, a token dump, and provenance for every value.

| System | Reference | Status |
| --- | --- | --- |
| [linear-baseline](linear-baseline/README.md) | linear.app, macOS 27, Bear | User-approved 2026-10-20 as the quality baseline |

A new system gets its own folder with the same layout: `README.md`, `figma/` exports, `tokens.json` and `tokens.md`, `provenance.md`.
