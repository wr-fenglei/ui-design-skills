# Reference Index

## Included assets

### [`01-18-icon-library.jpeg`](../assets/01-18-icon-library.jpeg)
A numbered 01–18 icon exploration sheet. Treat the numbering as authoritative for sequential discussions such as “start from 01, then 02, then 03”.

Use it to:
- identify the selected numbered direction
- compare visual distance between concepts
- preserve each concept's distinct design language
- prevent accidental mixing of adjacent directions

Do not use it to:
- copy exact shapes into new product marks
- average all directions into one blended style

### [`6EACF28D-C2BB-40AF-BA52-33E6AA9DDFBE.jpeg`](../assets/6EACF28D-C2BB-40AF-BA52-33E6AA9DDFBE.jpeg)
A six-icon reference sheet arranged in two rows, showing the directions corresponding to 01–06 in the numbered library at a larger scale. Use it to inspect silhouette, composition, material, and lighting details. Use the numbered library to identify directions.

## Reference hierarchy

1. User's selected numbered icon direction
2. Its extracted design thesis
3. Product requirements
4. Platform conventions

When these conflict, preserve the selected icon's design thesis while keeping the icon recognizable at its intended display sizes.
