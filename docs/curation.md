# 设计知识与典型示例的收录标准

## 方法与技能

有实际实践或可信参考支撑，能说明问题、输入、方法、产出、检查和适用边界。有限场景的经验保留条件，不写成普适审美定律，不为补齐目录制造空规则。

## 优秀典型示例

特别好、有代表性且有新参考价值的示例可以独立入库，不必先形成完整理论。保留明确认可范围的效果、制作方法和必要参数、为什么好、适用和未验证范围、来源与许可。可运行范例确实需要时，保留最小实现；不打包整批过程。

## 共同要求

- 用户认可局部不代表整页通过；自测不等于用户认可。
- 普通好示例先作为本地参考，不自动升级为技能。
- 探索方向应有结构差异，细化时固定无关变量。
- 代码运行、视觉效果、交互、真实产品验收分别记录。
- 引用和素材必须有来源与使用边界；不因入库授予原素材的额外许可。
- 图像生成与代码的分工由实际效果验证，不预设某种模型能包办完整页面。

实际调研、反馈、提取和清理流程只在 [蔚的工作规则](https://github.com/wr-fenglei/team-coordination/blob/main/%E8%94%9A/AGENTS.md) 维护。
