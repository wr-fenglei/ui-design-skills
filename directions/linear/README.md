# Linear Direction

A reference-calibrated direction: interfaces rebuilt from values measured on [linear.app](https://linear.app/), with product-window proportions from macOS 27 Finder and Mail, the HIG window anatomy and Bear. In the three-way comparison this direction contributes one version built with [reference calibration](../../references/reference-calibration.md) against its own contract.

- **Suitable starting question:** quiet product-led pages, restrained hierarchy and dense product UI, such as an embedded product mock or a desktop app window.
- **Explicit non-fit:** it is a deliberate imitation of Linear's system, not an original brand; do not ship it as one. Its one-accent palette, line-instead-of-shadow surfaces and radius scale belong to this direction only.
- **Status and evidence boundary:** accepted calibration example for the recorded dark Chinese marketing page (1440 / 390), user-approved on 2026-10-20 as more professional than the repository's earlier examples. Interaction remains untested.
