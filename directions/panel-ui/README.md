# Panel UI Direction

A reference-calibrated direction based on [Panel UI](https://panelui.dev/), the user-designated primary reference for this direction (added 2026-10-23). In the three-way comparison it contributes one version, built in Figma with the shared [reference calibration](../../references/reference-calibration.md) against inspected Panel UI components.

- **Suitable starting question:** component-rich interfaces with substantial control density and clear grouping. Inspect the task-specific components and their states first.
- **Explicit non-fit:** to be established by the first reproduction. Panel UI: Flow is a graph-canvas reference, not a generic page-layout template.
- **Status and evidence boundary:** **candidate; reproduction not yet established.** No validated specification, component set or complete-page reproduction exists in this repository. Source selection is not outcome approval.
